# Merry Xmas 明信片 · V3 更新说明

本版本保存了当前项目状态：

- `versions/v3/index.html`
- `versions/v3/server.js`
- `versions/v3/_redirects`

V3 相对 V2 的主要差异和功能如下。

## 1. URL 名称与页面交互

- 页面名称改为读取 URL 后面的第一段路径，例如 `/test` 显示名称“测试”。
- 英文名称统一为首字母大写、其余字母小写，例如 `/ALICE` 显示为 `Alice`。
- URL 路径匹配不区分大小写。
- 只有以下 6 个特殊 URL 支持按钮点击和左右滑动翻页：
  - `/ztj`
  - `/dw`
  - `/ly`
  - `/zj`
  - `/johnny`
  - `/test`
- 其他带名称的 URL 只显示名称，隐藏翻页按钮，也不支持滑动翻页，交互与默认 `/` 页面一致。
- 当前服务器启动提示中的示例地址已由 `maxiaobin` 改为 `test`。

## 2. 新增专属页面

- `/ztj`：名称为“张天娇”，背面使用“致我的朋友”祝福，落款为“—菲利帕·乔治乌”。
- `/dw`：名称为“戴雯”，使用野原新之助风格祝福，落款为“—野原新之助”。
- `/ly`：名称为“乐瑶”，使用利威尔·阿卡曼风格祝福，落款为“—リヴァイ·アッカーマン”。
- `/zj`：名称为“左洁”，使用 Lotso 专属祝福，落款为“—Lotso”。
- `/johnny`：保留 Johnny 专属祝福页面。
- `/test`：名称固定为“测试”，背面使用默认祝福内容。
- 以上专属路径均支持大小写混合形式，例如 `/DW`、`/Ly` 和 `/ZTJ`。

## 3. 背面内容滚动

- 卡片本身保持固定满屏展示，不再整体滚动。
- 默认祝福、Johnny 以及各个专属祝福区域可以在自己的文字区域内上下滚动。
- 移动端启用惯性滚动，避免长文本超出卡片。

## 4. 音乐播放

- 第一次点击翻页按钮或在正面完成滑动翻页时播放 `merry_xmas.mp3`。
- 音乐最大音量为 65%。
- 保留开头 2 秒渐入。
- 取消结尾渐出，音乐播放到文件结束后自然停止，不循环播放。
- 音乐播放通过用户点击或触摸手势直接触发，以适配移动端浏览器的自动播放限制。

## 5. iPhone 风格滑动翻页

- 正面点击按钮时继续使用原来的按钮点击样式。
- 正面左右滑动时，按钮会按照滑动方向填充：
  - 左向右滑动：从左向右填充。
  - 右向左滑动：从右向左填充。
- 滑动距离达到阈值后，按钮完成填充并自动翻页。
- 滑动距离不足时，按钮填充恢复。
- 文字颜色按照滑块覆盖范围变化，只有被填充区域内的文字变为浅色，未覆盖区域保持原颜色。
- 背面继续支持左右滑动返回正面。

## 6. 本地服务器和手机预览

- `server.js` 明确监听 `0.0.0.0`，允许同一局域网内的手机访问。
- 启动时自动打印可用的局域网访问地址。
- MP3 资源使用 `audio/mpeg` 返回。
- 增加 HTTP Range 分段响应，修复移动端音频播放提前截断的问题。
- 保留页面路径回退到 `index.html` 的行为。

## 7. V3 保存文件

- `versions/v3/index.html`：当前页面完整快照。
- `versions/v3/server.js`：当前本地预览服务器完整快照。
- `versions/v3/_redirects`：当前部署重写配置快照。
- `versions/v3/merry_xmas.mp3`：当前音乐文件快照，大小为 5,162,024 字节。

音乐文件内容没有改动，根目录中的 `merry_xmas.mp3` 与 V3 快照保持一致。
