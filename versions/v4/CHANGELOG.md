# Merry Xmas 明信片 · V4 更新说明

V4 保存了当前最新的页面、Netlify 路由配置、本地服务器和背景音乐文件。

## 文件

- `index.html`：页面主体。
- `_redirects`：Netlify 路由重写规则。
- `server.js`：本地 Node.js 预览服务器。
- `merry_xmas.mp3`：翻页时播放的背景音乐。

## V4 主要更新

### 加载页面

- 首页先显示加载页面，加载完成后进入明信片。
- 加载页面沿用主要页面的黎明前深蓝夜空风格。
- 加入缓慢飘落的雪花。
- 加载卡片内部保持干净，不显示雪花。
- 进度条采用不匀速推进，会有随机停顿和卡顿感。
- 进度条速度已适当加快。
- 进度达到 70%–90% 时显示：
  - 「圣诞老人正在敲门」
  - 「驼鹿门口吃草」
- 进度超过 90% 且未达到 100% 时显示：
  - 「圣诞老人正在翻烟囱」
  - 「驼鹿在门口画圈圈」
- 进度达到 100% 时显示：
  - 「礼物已抵达，请签收」
  - 「驼鹿跑远啦」
- 进度文字切换加入淡出、替换、淡入效果。
- 完成状态会停留约 1 秒，然后淡出进入明信片。
- 已移除进度条上的驼鹿、雪橇和雪花图标，恢复为纯金色进度条。
- 加载页到明信片的过渡经过优化：移除了可能导致手机卡顿的模糊和缩放，只保留轻微位移与淡入。

### 加载页面文字

- `A LITTLE WINTER WISH` 改为「雪夜寄怀·岁暮问安」。
- `Merry Xmas` 改为「圣诞快乐」。
- 「正在为你准备一份冬日心意」改为「圣诞老人正在加班派送中」。
- `PLEASE WAIT` 改为「驯鹿等红灯中」。

### 明信片正面

- 顶部显示「雪夜寄怀·岁暮问安」。
- 有名称的页面显示「谨以此小小心意，献给」、名称和「愿你所遇皆暖，所念皆成」。
- 默认页面显示「嘿，旅者」和「圣诞快乐」。
- 按钮显示「你终于来啦」和「轻点或滑动」。
- 默认页面隐藏按钮，但保留按钮占位，使标题和圣诞树位置不变。

### 名称和特殊路径

- 直接使用 URL 第一段作为名称，例如：
  - `/maxiaobin` → 显示 Maxiaobin。
  - `/测试` → 显示 测试。
- `/`、`/index` 和 `/index.html` 使用默认页面内容。
- 已保留特殊路径内容：
  - `/ztj`：张天娇专属文字。
  - `/dw`：戴雯专属文字。
  - `/ly`：乐瑶专属文字。
  - `/zj`：左洁专属文字。
  - `/johnny`：Johnny 专属文字。
  - `/swt`：孙琬婷，沿用菲利帕·乔治乌署名的祝福内容。

### 翻页和交互

- 支持点击按钮翻页。
- 支持在卡片正面和背面左右滑动翻页。
- 上下滑动仍可用于查看较长的背面内容。
- 第一次翻页时卡片和背景从黑白、夜色变为彩色和暖光。
- 第一次翻页时播放音乐、彩纸和烟花效果。
- 彩纸和烟花使用 canvas 绘制，不使用 emoji。
- 烟花会避开卡片区域，彩纸高度随机并形成错落感。
- 支持 Safari 小屏设备的 3D 翻页兼容处理。

### 视觉和布局

- 卡片适配手机和平板尺寸。
- 卡片外轮廓保持圆角，内侧细边框使用约 4px 圆角。
- 默认按钮使用浅灰线框和 4px 圆角，不使用块状背景。
- 翻页后的主色调整为金色、松绿和深棕，避免大面积红色。
- 正面标题、圣诞树和按钮的间距经过重新调整。

## 部署

- Netlify 使用根目录 `_redirects`：

```text
/*  /index.html  200
```

- 本地运行：

```bash
node server.js
```

- 本地名称测试：

```text
http://localhost:3000/测试
```
