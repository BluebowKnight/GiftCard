# Merry Xmas 明信片 · V4 更新说明

V4 保存了当前最新的页面、Netlify 路由配置、本地服务器和背景音乐文件。

## 文件

- `index.html`：页面主体。
- `_redirects`：Netlify 路由重写规则。
- `server.js`：本地 Node.js 预览服务器。
- `merry_xmas.mp3`：翻页时播放的背景音乐。

## V4 主要更新

### 加载页面

- 首页先显示加载页面，加载完成后进入明信片。
- 加载页面沿用主要页面的黎明前深蓝夜空风格。
- 加入缓慢飘落的雪花。
- 加载卡片内部保持干净，不显示雪花。
- 进度条采用不匀速推进，会有随机停顿和卡顿感。
- 进度条速度已适当加快。
- 进度达到 70%–90% 时显示：
  - 「圣诞老人正在敲门」
  - 「驼鹿门口吃草」
- 进度超过 90% 且未达到 100% 时显示：
  - 「圣诞老人正在翻烟囱」
  - 「驼鹿在门口画圈圈」
- 进度达到 100% 时显示：
  - 「礼物已抵达，请签收」
  - 「驼鹿跑远啦」
- 进度文字切换加入淡出、替换、淡入效果。
- 完成状态会停留约 1 秒，然后淡出进入明信片。
- 已移除进度条上的驼鹿、雪橇和雪花图标，恢复为纯金色进度条。
- 加载页到明信片的过渡经过优化：移除了可能导致手机卡顿的模糊和缩放，只保留轻微位移与淡入。

### 加载页面文字

- 顶部显示「雪夜寄怀·岁暮问安」。
- 有名称的页面显示「谨以此小小心意，献给」、名称和「愿你所遇皆暖，所念皆成」。
- 默认页面显示「嘿，旅者」和「圣诞快乐」。
- 按钮显示「你终于来啦」和「轻点或滑动」。
- 默认页面隐藏按钮，但保留按钮占位，使标题和圣诞树位置不变。

### 名称和特殊路径

- 只有以下 7 个特殊 URL 会显示名称、显示按钮，并支持点击和滑动翻页：
  - `/ztj`：名称为「张天娇」，使用专属祝福，落款「—菲利帕·乔治乌」。
  - `/swt`：名称为「孙琬婷」，沿用 `/ztj` 的专属祝福和落款。
  - `/dw`：名称为「戴雯」，使用野原新之助风格的专属祝福。
  - `/ly`：名称为「乐瑶」，使用利威尔风格的专属祝福。
  - `/zj`：名称为「左洁」，使用 Lotso 风格的专属祝福。
  - `/johnny`：名称为「Johnny」，使用欧罗林风格的专属祝福。
  - `/test`：名称为「测试」，使用默认背面祝福。
- URL 匹配不区分大小写，例如 `/Johnny` 和 `/johnny` 效果相同。
- 其他所有路径，例如 `/maxiaobin`、`/abc` 或 `/测试`，都按默认 `/index` 页面处理：
  - 正面显示「嘿，旅者」和「圣诞快乐」。
  - 隐藏按钮。
  - 不支持点击和滑动翻页。
- `/`、`/index` 和 `/index.html` 同样使用默认页面内容。

### 翻页和交互

- 支持点击按钮翻页。
- 支持在卡片正面和背面左右滑动翻页。
- 上下滑动仍可用于查看较长的背面内容。
- 第一次翻页时卡片和背景从黑白、夜色变为彩色和暖光。
- 第一次翻页时播放音乐、彩纸和烟花效果。
- 彩纸和烟花使用 canvas 绘制，不使用 emoji。
- 烟花会避开卡片区域，彩纸高度随机并形成错落感。
- 支持 Safari 小屏设备的 3D 翻页兼容处理。

### 视觉和布局

- 卡片适配手机和平板尺寸。
- 卡片外轮廓保持圆角，内侧细边框使用约 4px 圆角。
- 默认按钮使用浅灰线框和 4px 圆角，不使用块状背景。
- 翻页后的主色调整为金色、松绿和深棕，避免大面积红色。
- 正面标题、圣诞树和按钮的间距经过重新调整。

## 部署

- Netlify 使用根目录 `_redirects`：

```text
/*  /index.html  200
```

- 本地运行：

```bash
node server.js
```

- 本地名称测试：

```text
http://localhost:3000/测试
```

### 倒计时页面

- 首页流程为：倒计时卡片 → 加载卡片 → 明信片。
- 倒计时使用 5 秒示例。
- 倒计时格式为：`00 天 00 时 00 分 05 秒`。
- 天、时、分、秒分别独立渲染，只有发生变化的数字进行柔和翻牌。
- 倒计时文字为：
  - 「雪夜寄怀·岁暮问安」
  - 「距离圣诞节还有」
  - 「圣诞老人正在加班生产中...」
- 倒计时卡片和加载卡片尺寸一致，但使用独立卡片过渡，避免不自然的整张卡片翻转。
- 加载卡片在倒计时卡片淡出后出现，进度条随后开始推进。
